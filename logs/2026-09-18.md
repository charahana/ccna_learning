## OSI参照モデル
### 概要
- OSI参照モデルとは、ネットワーク通信に必要な機能を7つの階層に分けて整理したモデルである
- 複雑なネットワーク通信を役割ごとに分けることで、通信の仕組みを理解しやすくなり、障害が発生した際にも原因を特定しやすくなる
- 通信のどの部分で問題が発生しているのかを把握できる
- 通信に関係する機器やプロトコルを整理できる
- ネットワークの仕組みを階層ごとに理解できる

### OSI参照モデルとは
OSI参照モデルは、ネットワーク通信の機能を7つの層に分けて考えるためのモデルである
各層はそれぞれ異なる役割を持ち、連携することでデータの送受信を実現する

### OSI参照モデルの7階層
| 層 | 名称 | 主な役割 |
| ------ | ------ | ------ |
| 第7層 | アプリケーション層 | アプリケーションが利用するネットワークサービス |
| 第6層 | プレゼンテーション層 | データ形式の変換、暗号化、圧縮など |
| 第5層 | セッション層 | 通信セッションの確立・維持・終了 |
| 第4層 | トランスポート層 | データの分割、端末間の通信、通信の信頼性など |
| 第3層 | ネットワーク層 | IPアドレスによる論理的な宛先指定と経路選択 |
| 第2層 | データリンク層 | 同じリンク内でのフレームの送受信 |
| 第1層 | 物理層 | 電気信号・光信号・電波などによるデータ伝送 |

## 各層の役割
### 第7層：アプリケーション層
- アプリケーションがネットワークサービスを利用するための機能を提供する層
#### 代表的なプロトコル
- HTTP / HTTPS：Web通信
- DNS：ドメイン名とIPアドレスの対応付け
- SMTP：電子メールの送信・転送
- FTP：ファイル転送

### 第6層：プレゼンテーション層
- アプリケーション間で扱うデータの表現形式を整える役割を持つ
### 主な役割
- データ形式の変換
- 文字コードなどの表現形式の調整
- 暗号化・復号
- 圧縮・展開

### 第5層：セッション層
- 通信する機器やアプリケーション間のセッション（通信のやり取り）を管理する層
#### 主な役割
- セッションの確立
- セッションの維持・管理
- セッションの終了

### 第4層：トランスポート層
- アプリケーション間のデータ転送を制御する層。通信方式に応じて、信頼性や転送効率などを調整する。
#### 代表的なプロトコル
- TCP：接続を確立し、データの順序や再送などを制御して信頼性の高い通信を実現する
- UDP：接続確立などの手順を省き、少ない制御でデータを送信する
- ポート番号を利用して、どのアプリケーション宛てのデータなのかを識別する
