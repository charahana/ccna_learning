## Linuxのネットワーク設定と確認コマンド
### 概要
- Linuxサーバがネットワーク通信を行うためには、IPアドレスやサブネットマスク、デフォルトゲートウェイ、DNSサーバなどのネットワーク設定が必要になる
- Linuxでは、コマンドを使用することでネットワーク設定の確認や変更、通信状態の調査を行うことができる

### Linuxのネットワーク設定とは
| 設定項目 | 役割 |
| ------ | ------ |
| IPアドレス | ネットワーク上で機器を識別するためのアドレス |
| サブネットマスク | IPアドレスのネットワーク部とホスト部を区別する |
| デフォルトゲートウェイ | 異なるネットワークへ通信するときの出口となるルータ |
| DNSサーバ | ドメイン名からIPアドレスを調べる |
| ネットワークインターフェース(NIC) | ネットワークに接続するための通信機能/接続口 |

### ネットワークインターフェース(NIC)
- NIC(Network Interface Card)とは、コンピュータをネットワークに接続するための機器/機能のことである
- Linuxでは、ネットワークインターフェースごとに名前が付けられている。
#### 代表的なインターフェース名
- eth0：従来から使われている有線LANのインターフェース名
- ens33：予測可能なインターフェース名の一例
- enp0s3：PCIバスなどの位置情報を基にしたインターフェース名
- lo：ループバックインターフェース。自分自身との通信に使用する
#### NICの確認コマンド
- ネットワークインターフェースの一覧や状態を確認できる

### IPアドレスの確認
#### ip addr show
- IPアドレスやサブネットマスク、ネットワークインターフェースの状態などを確認できる

### デフォルトゲートウェイ・ルーティングの確認
- Linuxでは、ルーティングテーブルを確認することで、宛先ネットワークへの通信経路を確認できる
#### ip route show
- Linuxのルーティングテーブルを表示するコマンド
#### ip route | grep default
- ルーティングテーブルの中から、デフォルトルートに関する情報だけを表示するコマンド

### DNSサーバの確認
- DNSサーバの設定を確認するには、次のコマンドを使用する
#### cat /etc/resolv.conf
- /etc/resolv.confには、名前解決に使用するDNSサーバなどの情報が記載されている

### nmcliとは
- nmcliとは、LinuxのNetworkManagerをコマンドラインから操作するためのコマンド
- ネットワーク設定の確認だけでなく、接続設定の変更や有効化/無効化なども行える
#### 代表的なコマンド
| コマンド | 用途 |
| ------ | ------ |
| nmcli device status | ネットワークデバイスの状態を確認 |
| nmcli connection show | 接続設定の一覧を確認 |
| nmcli connection show --active | 現在有効な接続を確認 |
| nmcli device show | デバイスの詳細情報を確認 |
#### 主なポイント
- NetworkManagerを操作するためのコマンド
- ネットワーク設定の確認や変更に使用する
- GUIを使わずにコマンドラインから設定できる

### Pingによる疎通確認
- PingとはICMPのEcho RequestとEcho Replyを利用して、相手の機器と通信できるかを確認するコマンド
- ネットワーク設定を行った後や、通信できない場合の原因調査に使用する
#### ping 192.168.1.1
- 指定したIPアドレスの機器に対して通信を確認する。
#### 主に確認できる情報
- 相手の機器から応答があるか
- 応答までにかかった時間
- パケットの送信数/受信数/損失率

### ネットワーク確認コマンド早見表
| 確認内容 | Linuxコマンド |
| ------ | ------ |
| IPアドレス | ip addr show |
| NIC/インターフェース | ip link show |
| ルーティングテーブル | ip route show |
| デフォルトゲートウェイ | `ip route | grep default` |
| DNSサーバ | cat /etc/resolv.conf |
| ネットワークデバイスの状態 | nmcli device status |
| 接続設定 | nmcli connection show |
| 疎通確認 | ping |
