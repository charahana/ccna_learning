## カプセル化とイーサネットフレーム
### 概要
コンピュータネットワークでは、データを正しく送信・受信するために決められた形式やルールに従って通信を行う。
データを別の形式の中に入れて送信することをカプセル化といい、受信側でその情報を取り出すことをカプセル化解除という。
イーサネットではデータを決められた形式のイーサネットフレームにカプセル化して送信する

## Ethernetとイーサネットフレーム
### Ethernetとは
EthernetはLANなどで広く利用されているネットワーク通信の規格である。

### Ethernetのルール
- フレームのフォーマット
- フレームのサイズ
- 通信のタイミング
- データのエンコーディング

### イーサネットフレームとは
イーサネットフレームとはEthernetでデータを送信するための決められた形式である。
フレームにはデータだけでなく、通信に必要な様々な情報が含まれている。

### イーサネットフレームの主な情報
| 項目 | 役割 |
| ------ | ------ |
| 宛先MACアドレス | フレームの送信先を識別する |
| 送信元MACアドレス | フレームの送信元を識別する |
| プリアンブル | 通信の同期に使用される |
| フレーム開始デリミタ(SFD) | フレームの開始を示す |
| タイプ | フレームの長さや上位プロトコルの種類などを示す |
| データ | 実際に伝送するデータ |
| FCS | 伝送中のエラーを検出するために使用する |

### 学び
- カプセル化とはあるメッセージ形式を別の形式の中に入れるプロセスであることを理解した
- Ethernetには通信を行うための様々な規格やルールが定められていることを理解した
- Ethernetではデータをイーサネットフレームにカプセル化して送信することを学んだ
- イーサネットフレームには宛先MACアドレスや送信元MACアドレスなどの情報が含まれることを理解した
