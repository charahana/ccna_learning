## ブロードキャストドメインとセグメンテーション
### ブロードキャスト
- 同じネットワーク内に存在する複数のデバイスへ一斉にデータを送信する通信方法である
- Ethernetでは宛先MACアドレスにブロードキャストアドレスを使用する
- ARPやDHCPなどで利用される
- スイッチはブロードキャストを同じブロードキャストドメイン内へ転送する
- ルーターは基本的にブロードキャストを別のネットワークへ転送しない

### ブロードキャストドメイン
- ブロードキャストが到達できる範囲
- ルーターによって分割される
- ルーターの各インターフェースは異なるブロードキャストドメインに接続される
- ブロードキャストドメインが大きくなるとブロードキャストによる通信量が増える可能性がある

### ルーターによるセグメンテーション
- ルーターは異なるネットワークを接続するだけでなく、ブロードキャストドメインを分割する役割も持つ
- ブロードキャストの境界線である

### ARP
IPv4アドレスから対応するMACアドレスを調べるために使用される。

### DHCP
IPアドレスを取得するためにクライアントがブロードキャストを利用する。

### スイッチとルーターの違い
| 項目 | スイッチ | ルーター |
| ------ | ------ | ------ |
| 主に扱う情報 | MACアドレス | IPアドレス |
| 主な役割 | LAN内の機器を接続 | 異なるネットワークを接続 |
| ブロードキャスト | 同一ドメイン内へ転送 | 基本的に転送しない |
| ブロードキャストドメイン | 基本的に分割しない | 分割する |
| OSI参照モデル | L2 | L3 |
