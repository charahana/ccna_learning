## Linuxの基礎
### 概要
- Linuxはサーバやネットワーク機器などで広く利用されているOSの一種であり、ハードウェアとアプリケーションの間を管理し、コンピュータが動作するための基本的な機能を提供する
- Linuxの基本構造、ディストリビューション、ディレクトリ構造、ユーザと権限について学習する

### Linuxとは
- ハードウェアとアプリケーションの間を仲介する
- CPUやメモリなどのリソースを管理する
- サーバ用途で広く利用されている
- コマンドを使ってシステムの設定や管理を行える

### Linuxの基本構造
- Linuxを操作するうえで特に重要なのが「カーネル」と「シェル」である

### カーネル（Kernel）
- OSの中核となる部分であり、ハードウェアやシステムリソースを管理する
- CPUの管理
- メモリの管理
- プロセスの管理
- デバイスの管理
- ファイルシステムの管理

### シェル（Shell）
- ユーザが入力したコマンドを解釈し、OSに処理を依頼する仕組みである
- ユーザからコマンドを受け取る
- コマンドを解釈して実行につなげる
- 実行結果をユーザに返す

## Linuxディストリビューション
- LinuxディストリビューションとはLinuxカーネルに加えてコマンドやライブラリ、管理ツールなどを組み合わせて利用できるようにしたOSの配布形態である
### 代表的なディストリビューションは以下である
#### Red Hat系
- RHEL（Red Hat Enterprise Linux）：企業向けの商用Linux
- Rocky Linux：RHELとの互換性を重視したLinux
- AlmaLinux：RHELとの互換性を重視したLinux
- Fedora：新しい技術を積極的に取り入れるLinux

#### Debian系
- Debian：安定性を重視したLinux
- Ubuntu：デスクトップやサーバなど幅広い用途で利用されるLinux

### Linuxのディレクトリ構造
| ディレクトリ | 主な用途 |
| ------ | ------ |
| / | すべてのディレクトリの起点 |
| /etc | システムやアプリケーションの設定ファイル |
| /home | 一般ユーザのホームディレクトリ |
| /root | rootユーザのホームディレクトリ |
| /var | ログやメールなど、変化するデータ |
| /tmp | 一時ファイル |
| /usr | 多くのコマンド、ライブラリ、共有データなど |
| /boot | OSの起動に必要なファイル |

### ユーザと権限
- Linuxでは、ユーザやグループごとにファイルやディレクトリへのアクセス権限を設定できる
- 不要な変更や情報へのアクセスを防ぐ

### ユーザーの種類
- rootユーザ：システム全体を管理できる強力な権限を持つユーザ
- 一般ユーザ：通常の作業に使用するユーザ
- グループ：複数のユーザをまとめ、共通の権限を設定するための仕組み

### ファイルの所有者
- ファイルやディレクトリには所有者が設定される。権限は、主に所有者・所有グループ・その他のユーザという区分で管理される

### 基本的なアクセス権限
| 権限 | 記号 | 意味 |
| ------ | ------ | ------ |
| 読み取り | r | ファイルの内容を読み取る | 
| 書き込み | w | ファイルの内容を変更する |
| 実行 | x | ファイルを実行する。ディレクトリでは内容の検索・アクセスに関係する |

### 学び
- Linuxはサーバなどで広く利用されるOSである
- カーネルはシステムリソースを管理し、シェルはコマンドを解釈してOSに処理を依頼する
- ディストリビューションには、RHEL系やDebian系などの系統がある
- Linuxのファイルは、ルートディレクトリ / を起点とする階層構造で管理される
- ユーザやグループ、アクセス権限によって、ファイルやディレクトリへの操作を制御できる
