## IPアドレスの割り当て
### 概要
インターネット上でグローバルにルーティングされるパブリックIPv4アドレスは、世界中で重複しないように管理・割り当てられている。

### IANA
IANAとは、インターネットで使用されるIPアドレスなどの番号資源を全体的に管理・調整する組織である。

### RIR
RIRとは地域ごとにIPアドレスなどのインターネット資源を管理する組織である。

### 5つのRIR
| RIR | 担当地域 |
| ------ | ------ |
| ARIN | 北米 |
| RIPE | ヨーロッパ・中東など |
| APNIC | アジア太平洋地域(日本含む) |
| LACNIC | 中南米・カリブ海地域 |
| AFRINIC | アフリカ地域 |

### パブリックIPv4アドレス
パブリックIPv4アドレスとは、インターネット上でグローバルにルーティングされるIPv4アドレスである。

### 学び
- パブリックIPv4アドレスはインターネット上でグローバルにルーティングされるアドレスであることを学んだ
- IANAがIPアドレスの大きなブロックを管理し、RIRへ割り当てていることを学んだ
- RIRは地域ごとにIPアドレスを管理し、ISPや組織などへ割り当てていることを理解した

### 今後に活かすこと
- IANAやRIRの役割の違いを説明できるようにする
- 5つのRIRとそれぞれの担当地域を覚える
