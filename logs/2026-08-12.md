## ルーティングテーブル
### 概要
- ルーティングテーブルとは、ルーターがパケットを転送する際にしようす情報をまとめた表です
- ルーティングテーブルには、宛先となるネットワークアドレスと、そのネットワークへ到達するための経路情報が登録されている
- ルーターは宛先IPアドレスを確認し、ルーティングテーブルを参照して転送先のインターフェースを決定する
- ルーティングテーブルの情報は、管理者が手動で設定する方法と、ルーティングプロトコルなどによって動的に学習する方法がある

### ルーティングテーブルの例
| タイプ | ネットワーク | ポート |
| ------ | ------ | ------ |
| C | 192.168.1.0/24 | G0/0 |
| C | 192.168.2.0/24 | G0/1 |
| S | 192.168.3.0/24 | G0/2 |

### ルーティングテーブルのタイプ
- C = ルーターのインターフェースに直接接続されているネットワーク
- S = 管理者が手動で設定した静的ルート

### 学び
- ルーターはルーティングテーブルを参照して、パケットの転送先を決定することを理解した
- ルーティングテーブルには宛先ネットワークとそのネットワークへ到達するための経路情報が登録されていることを学んだ
- ルーティング情報には、直接接続されたネットワークや管理者が設定する静的ルートなどがあることを理解した
- ルーティングテーブルに宛先ネットワークへの経路が存在しない場合、パケットが破棄されることを学んだ
- デフォルトルートを設定することで、ルーティングテーブルに存在しない宛先へのパケットを別のルーターへ転送できることを理解した
