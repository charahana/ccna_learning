## リモートネットワーク上の宛先
### 概要
ホストが通信する時、宛先IPアドレスが自分とは異なるネットワーク(リモートネットワーク)にある場合、ホストは直接宛先ホストへフレームを送信することはできない。
この場合、ホストはデフォルトゲートウェイであるルーターへフレームを送信する。

### IPアドレスとMACアドレスの違い
| 項目 | IPアドレス | MACアドレス |
| ------ | ------ | ------ |
| OSI層 | L3 | L2 |
| 主な役割 | 最終的な通信相手を識別 | 次のリンク上の相手へ届ける |
| ルーターを通過 | 基本的に維持 | 次のリンクごとに変化 |
| 使用されるもの | IPパケット | Ethernetフレーム |

### ルーターでの処理
- 宛先IPアドレスを確認して転送先を決定する
- 受信したEthernetフレームをカプセル化する

### 学び
- 宛先IPアドレスがリモートネットワークにある場合、デフォルトゲートウェイへフレームを送信することを学んだ
- リモートネットワークへの通信では、最初の宛先MACアドレスが最終宛先ではなくデフォルトゲートウェイになることを理解した
- ルーターはEthernetフレームを受信すると、レイヤ2情報をカプセル化して宛先IPアドレスを確認することを学んだ
- ルーターはルーティングテーブルを使用して次の転送先を決定することを理解した
- ルーターを通過するたびに、新しいデータリンクフレームへIPパケットが再カプセル化されることを学んだ
- IPアドレスは最終的な宛先を示す一方、MACアドレスはその時点のリンク上で次に転送する相手を示すことを理解した
