## オクテットとドット付き十進表記
### 概要
IPv4アドレスは32ビットで構成されている。
32ビットをそのまま表記すると非常に長く読みにくいため、IPv4アドレスでは32ビットを8ビットずつ
4つのグループに分けて表記する。
この8ビットのグループをオクテットと呼ぶ。
また、それぞれのオクテットを10進数に変換し、ピリオドで区切って表記する方法をドット付き十進表記という。

### オクテットとは
オクテットとは、8ビットのまとまりのことである。

### 2進数から10進数へ
| ビット | 値 |
| ------ | ------ |
| 1ビット目 | 128 |
| 2ビット目 | 64 |
| 3ビット目 | 32 |
| 4ビット目 | 16 |
| 5ビット目 | 8 |
| 6ビット目 | 4 |
| 7ビット目 | 2 |
| 8ビット目 | 1 |

### 学び
- IPv4アドレスは32ビットで構成されていることを理解した
- 32ビットを8ビットずつ4つのグループに分けることを学んだ
- 8ビットのグループをオクテットと呼ぶことを理解した
- 1つのオクテットは0～255の範囲で表現されることを学んだ
