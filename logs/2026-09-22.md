## 通信プロトコル/TCPとUDP/ポート番号
### 概要
- ネットワーク上でコンピュータ同士が通信するためには通信の手順やデータの扱い方を定めたルールが必要になる
- このルールを通信プロトコルと呼ぶ
- 通信プロトコルには様々な種類があり、TCPやUDPはデータを送受信する際に使用される代表的なプロトコルである

### 通信プロトコルとは
- プロトコルとはコンピュータ同士が通信するためのルール(通信規約)のこと
- 異なるコンピュータや機器同士でも共通のプロトコルに従うことで通信できる
#### 代表的な通信プロトコル
| プロトコル | 主な役割 |
| ------ | ------ |
| HTTP | Webサイトの情報を送受信する |
| HTTPS | 暗号化してWebサイトの情報を送受信する |
| DNS | ドメイン名をIPアドレスに変換する |
| DHCP | IPアドレスなどのネットワーク設定を自動で割り当てる |
| SMTP | メールを送信する |
| SSH | 暗号化された通信でサーバなどを遠隔操作する |
| FTP | ファイルを転送する |
| TCP | 信頼性を重視してデータを送受信する |
| UDP | 効率や速度を重視してデータを送受信する |

### TCPとUDP
- TCPとUDPはトランスポート層(OSI参照モデルの第4層)で使用される代表的なプロトコルのこと
- アプリケーション間のデータ通信を支える役割を持つ
#### TCP
- 通信を開始する前にコネクション(論理的な通信経路)を確立する
- 3ウェイハンドシェイクによって通信を開始する
- シーケンス番号を使用してデータの順序を管理する
- データが届かなかった場合、再送する仕組みがある
- データの到着確認や順序制御などを行う
#### UDP
- 通信前にコネクションを確立しない
- TCPのような再送制御や順序制御を基本的に行わない
- ヘッダーが比較的シンプルで通信処理の負担が小さい
- データが届かない場合でもUDP自体では再送しない
#### TCPとUDPの比較
| 比較項目 | TCP | UDP |
| ------ | ------ | ------ |
| 通信方式 | コネクション型 | コネクションレス型 |
| 接続確認 | あり | なし |
| 再送制御 | あり | 基本的になし |
| 順序制御 | あり | なし |
| 通信の特徴 | 信頼性を重視 | 効率/速度を重視 |
| 主な用途 | Web、メール、ファイル転送など | DNS、音声/動画通信など |

### ポート番号
- 1台のコンピュータの中で、どのアプリケーションやサービス宛ての通信なのかを識別するための番号のこと
- IPアドレスが通信相手となるコンピュータやネットワーク上の機器を識別するのに対し、ポート番号はそのコンピュータ内の通信先を識別する役割を持つ
#### ポート番号の範囲
- 0~65535まで使用できる
- TCPとUDPそれぞれにポート番号がある
#### 代表的なポート番号
| ポート番号 | プロトコル | 用途 |
| ------ | ------ | ------ |
| 20-21 | FTP | ファイル転送 |
| 22 | SSH | 暗号化された遠隔操作 |
| 23 | Telnet | 遠隔操作 |
| 25 | SMTP | メール送信 |
| 53 | DNS | 名前解決 |
| 67-68 | DHCP | IPアドレスの自動割り当て |
| 80 | HTTP | Web通信 |
| 110 | POP3 | メール受信 |
| 443 | HTTPS | 暗号化されたWeb通信 |

### IPアドレスとポート番号の関係
- IPアドレスとポート番号を組み合わせることで通信相手のコンピュータとその中の通信先アプリケーションを識別できる

- ポート番号はコンピュータ内のアプリケーションやサービスを識別するために使用されることを理解した
