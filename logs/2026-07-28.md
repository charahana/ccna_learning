## IPv6の必要性
### 概要
IPv4は32ビットのアドレス空間を持ち、理論上約43億個のIPv4アドレスを利用できる
しかしインターネット利用者や接続するデバイスの増加によってIPv4アドレスは不足するようになった。
特にスマートフォンやloTデバイスなど、インターネットへ接続する機器が増加しているため、IPv4だけでは今後のインターネットの成長に対応することが難しくなっている。そこでIPv4の後継として設計されたのがIPv6である。

### IPv4アドレスの枯渇の背景
- インターネット利用者の増加
- スマートフォンなどのモバイル端末の増加
- loTデバイスの増加
- インターネットへ接続する機器の増加

### NATによるIPv4アドレス枯渇への対応
IPv4アドレスの不足に対応するため、プライベートIPv4アドレスとNATが広く利用されていた。そのため、IPv4アドレスの消費を抑えることができた。

### NATのデメリット
- 通信が複雑になる
- アプリケーションによっては通信に問題が発生する場合がある
- エンドツーエンド通信を実現しにくい
- ピアツーピア通信などに影響する場合がある

### IPv6
IPv6はIPv4の後継として設計されたプロトコルである。
IPv4の32ビットに対して、IPv6は128ビットのアドレス空間を持つ。
IPv6では非常に大きなアドレス空間を利用できるため、増加し続けるインターネット接続機器に対応できる。

### IPv6はアドレス数が多いだけではない
- より大きな空間
- アドレス自動構成
- IPv6に対応したアドレス解決

### IPv6とloT
loTとは様々な「モノ」をインターネットへ接続する仕組みである。
loTによってインターネットに接続されるデバイスがさらに増加すると、必要となるIPアドレスも増加する。
そのため、膨大なアドレス空間をもつIPv6の重要性がさらに高まっている。

### IPv6が必要とされる理由
| 理由 | 内容 |
| ------ | ------ |
| IPv4アドレス枯渇 | IPv4のアドレス数には限りがある |
| インターネット利用者の増加 | 接続するユーザーが増加している |
| モバイル端末の増加 | スマートフォンなどの接続機器が増加 |
| loTの普及 | 多数のデバイスがインターネットへ接続 |
| NATの制限 | NATによって通信に制約が発生する場合がある |
| 大きなアドレス空間 | IPv6は128ビットのアドレス空間を持つ |

### IPv4とIPv6の比較
| 項目 | IPv4 | IPv6 |
| ------ | ------ | ------ |
| アドレス長 | 32ビット | 128ビット |
| アドレス数 | 約43億 | 約3.4 * 10^38 |
| アドレス表記 | 192.168.1.1 | 2001:db8::1 |
| アドレス枯渇 | 問題になっている | 非常に大きなアドレス空間 |
| NAT | 広く利用 | IPv4ほど必要とされない |
| アドレス自動構成 | DHCPなど | SLAACなど |
