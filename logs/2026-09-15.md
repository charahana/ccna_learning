## コンピュータの基礎とサーバ
### コンピュータとは
- コンピュータとは入力されたデータをプログラムに従って処理し、その結果を出力・保存する機器のこと
- コンピュータは入力・処理・出力・保存という基本的な動作によって様々な情報を扱う
- 入力 : キーボート、マウス、ネットワークなどからデータを処理する
- 処理 : CPUがプログラムの命令を実行し、データを処理する
- 出力 : 処理結果を画面に表示したり印刷したりネットワークへ送信したりする
- 保存 : SSDやHDDなどにデータを保存する
- コンピュータは大きく分けてハードウェアとソフトウェアで構成される

### ハードウェア
- ハードウェアとはコンピュータを構成する物理的な機器や部品のこと
- 実際に触れるものができるものが多い
- CPU/メモリ/SSD/HDD/NIC/マザーボード/電源装置が主に構成されている

### ソフトウェア
- ソフトウェアとはコンピュータ上で動作するプログラムのこと
- ハードウェアに処理を実行させたりユーザがコンピュータを操作できるようにしたりする

### 主な種類
- OS(オペレーティングシステム) : ハードウェアやソフトウェアを管理する
- ミドルウェア : OSとアプリケーションの間などで共通機能を提供する
- アプリケーション : Webブラウザやメールソフトなどユーザが目的に応じて利用するソフトウェアのこと
- デバイスドライバ : OSがハードウェアを制御するためのソフトウェアのこと

### 主要なハードウェア
| 構成要素 | 主な役割 | イメージ |
| ------ | ------ | ------ |
| CPU | 命令の実行や計算処理を行う | 頭脳 |
| メモリ | 処理中のデータやプログラムを一時的に保持する | 作業机 |
| SSD/HDD | データやプログラムを長期的に保存する | 書庫 |
| NIC | コンピュータをネットワークに接続する | 通信の出入口 |
| マザーボード | CPUやメモリなどの部品を接続する | 土台 |
| 電源装置 | 各部品に必要な電力を供給する | 電力供給源 |

### CPU/メモリ/SDD/HDDの違い
- CPU : プログラムの命令を実行し計算や処理を行う
- メモリ : CPUが処理に使用するデータやプログラムを一時的に保持する
- SDD/HDD : OSやアプリケーション、ファイルなどを長期的に保存する

### NIC(ネットワークインターフェースカード)
- NICはコンピュータをネットワークに接続するためのハードウェア
- EthernetやWi-Fiなどのネットワーク通信に使用される
- ネットワーク上の他の機器とデータを送受信するために必要となる

### サーバ
- サーバとはネットワークなどを通じて他のコンピュータに機能やデータなどのサービスを提供する仕組みのこと
- サービスを提供する側をサーバ、サービスを利用する側をクライアントと呼ぶ
- サーバは専用のコンピュータを指す場合とサービスを提供するソフトウェアを指す場合がある

## サーバの種類
### Webサーバ
- Webブラウザからの要求を受け取り、Webページなどのコンテンツを返す
- HTTPやHTTPSを使用して通信する

### アプリケーションサーバ
- アプリケーションの処理や業務ロジックを実行する
- ユーザからの要求に応じて計算やデータ処理を行う

### データベースサーバ
- データを保存・管理する
- アプリケーションなどからの要求に応じて、データの検索・登録・更新・削除などを行う

### メールサーバ
- 電子メールの送受信や保存を行う
- SMTP/POP3/IMAP4などのメール関連プロトコルを使用する

### サーバの役割の比較
| サーバの種類 | 主な役割 | 関連する技術・プロトコル |
| ------ | ------ | ------ |
| Webサーバ | Webコンテンツの提供 | HTTP/HTTPS |
| アプリケーションサーバ | アプリケーションの処理 | アプリケーションにより異なる |
| データベースサーバ | データの保存・管理 | SQL・データベース製品ごとの通信方式 |
| メールサーバ | メールの送受信・保存 | SMTP・POP3・IMAP4 |
