## サブネットマスクの基礎
### 概要
- サブネットとは1つのネットワークを複数の小さなネットワークに分割したものである
- ネットワークを分割することでIPアドレスを効率的に利用でき、ネットワークの管理や通信の制御がしやすくなる
- IPv4アドレスは32ビットで構成され、サブネットマスクによってネットワーク部とホスト部を区別できる

### サブネットとは
- IPv4アドレスは32ビットで構成され、サブネットマスクのビットによってネットワーク部とホスト部を判断する

### プレフィックス長
- プレフィックス長とはIPアドレスのネットワーク部が何ビットあるかを表す数値である
- サブネットマスクは/24のように表記でき、これをCIDR表記(プレフィックス表記)という

### プレフィックス長とサブネットマスクの対応
| プレフィックス長 | サブネットマスク |
| ------ | ------ |
| /24 | 255.255.255.0 |
| /25 | 255.255.255.128 |
| /26 | 255.255.255.192 |
| /27 | 255.255.255.224 |
| /28 | 255.255.255.240 |
| /29 | 255.255.255.248 |
| /30 | 255.255.255.252 |
| /31 | 255.255.255.254 |
| /32 | 255.255.255.255 |

### IPアドレスの3種類
- 一般的なIPv4サブネットマスクではIPあどれすは次の3種類に分けて考える
#### ネットワークアドレス
- ホスト部が全て0
- ネットワークを識別するために使用する
- 通常、PCやサーバなどには割り当てない
#### ホストに割り当て可能なアドレス
- ネットワークアドレスとブロードキャストアドレスの間の範囲
- ネットワーク内の機器を識別するために使用する
#### ブロードキャストアドレス
- ホスト部が1
- 同一ネットワーク内の全体にデータを送信する際に使用する
- 通常、PCやサーバなどには割り当てない

### ホスト数の計算
- サブネット内でホストに割り当て可能なIPアドレス数はホスト部のビット数から計算できる
- 一般的なIPv4サブネットでは次の計算式を使用する
#### 計算式
- ホスト部のビット数 = 32 - プレフィックス長
- 使用可能なホスト数 = 2の(ホスト部のビット数)乗 - 2

### 学び
- サブネットマスクは1つのネットワークを複数の小さなネットワークに分割したものであることを理解した
- サブネットマスクの1がネットワーク部、0がホスト部を表すことを理解した
- プレフィックス長はネットワーク部のビット数を表すことを理解した
- サブネットマスクによって、ネットワーク部とホスト部の境界を判断できることを理解した
- ホスト部のビット数によって、ネットワーク内で使用できるIPアドレス数が決まることを理解した
- プレフィックス長が大きくなるほど、1つのサブネットで利用できるホスト数は少なくなることを学んだ
