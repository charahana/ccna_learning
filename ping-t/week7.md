# 間違えた問題まとめ
## 1. 1000BASE-ZX(SMF)の最大伝送距離はどれか。
### 間違いポイント
イーサネット規格の各距離を整理できなかった
### 正解
- 約70Km
### 重要なポイント
- 光ファイバーケーブルを利用する主なイーサネット規格は下記となる
| 規格 | 最大伝送距離 |
| ------ | ------ |
| 1000BASE-LX(SMF) | 5Km |
| 1000BASE-LX(MMF) | 550m |
| 1000BASE-LX/LH(SMF) | 10Km |
| 1000BASE-LX/LH(MMF) | 550m |
| 1000BASE-SX(MMF) | 550m |
| 1000BASE-ZX(SMF) | 約70Km |
| 10GBASE-LR(SMF) | 10Km |
| 10GBASE-SR(MMF) | 300m |

## 2. MMFで一般敵に使用されるコア径は次のうちどれか(2つ選択)
### 間違いポイント
SMFのコア径と混同してしまった
### 正解
- 50μm
- 62.5μm
### 重要なポイント
- SMFとMMFのコア径は下記となる
| 伝搬モード | 規格 | コア径 |

| シングル | OS1 | 8～10μm |
| シングル | OS2 | 8～10μm |
| マルチ | OM1 | 62.5μm |
| マルチ | OM2 | 50μm |
| マルチ | OM3 | 50μm |
| マルチ | OM4 | 50μm |
| マルチ | OM5 | 50μm |

## 3. PSEとPDについて正しい記述はどれか(2つ選択)
### 間違いポイント
PoEの仕組みをきちんと理解できなかった
### 正解
- PSEは電力を供給する側を指す
- アクセスポイントはPDに該当する
### 重要なポイント
- PSEとは電力を供給するデバイス(スイッチや電源装置などの給電装置)のことです
- PDとは電力の供給を受けるエンドデバイス(IP Phoneやアクセスポイントなどの受電装置)のことです
