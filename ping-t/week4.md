# 間違えた問題まとめ
## 1. 選択肢のうち、オンプレミスの特徴はどれか(2つ選択)
### 間違いポイント
オンプレミスとクラウドとの違いを理解できなかった
### 正解
- 初期費用が高い
- サーバやネットワークを自社で管理する必要がある
### 重要なポイント
- オンプレミスとはサーバなどを自社で運用することを指す
- オンプレミスとクラウドの比較は下記となる
| クラウド | オンプレミス |
| ------ | ------ |
| 初期費用が安い | 初期費用が高い |
| 使用した分だけ費用が掛かる | どれだけ使用しても追加費用は掛からない |
| 契約してすぐに使用可能 | 機器の導入や構築に時間が掛かる |
| 提供されているサービスの範囲でしかカスタマイズできない | 自社の要件に応じて物理構成を自由にカスタマイズできる |

## 2. 一台の物理サーバ上で動作する仮想マシンについて正しい記述はどれか(2つ選択)
### 間違いポイント
仮想マシンとハイパーバイザーとの関係を理解できなかった
### 正解
- 仮想マシンはそれぞれ独立して動作する
- 仮想マシンごとに異なるOSを動かすことができる
### 重要なポイント
- 一台の物理サーバに作成された仮想マシンは、それぞれが一台の物理コンピュータであるかのように動作する
- ある仮想マシンの起動、停止、管理などの操作によって別の仮想マシンが影響を受けることがなく、それぞれが独立して動作する

## 3. 一つのプロセスで同時に複数の処理を行う技術を何というか。
### 間違いポイント
同時に動作する環境と同じ仮想化と混同してしまった
### 正解
- マルチスレッド
### 重要なポイント
- 一つのプロセスで同時に複数の処理を行う技術は「マルチスレッド」です
- 一方、同時に一つの処理しか行えない状態を「シングルスレッド」という
- マルチスレッドにより、同時に複数の処理を行うことが可能となるのでプログラムの効率性とパフォーマンスを向上できる

## 4. 非同期転送に該当する通信は次のうちどれか(2つ選択)
### 間違いポイント
同期転送と混同してしまった
### 正解
- コンソール接続によるネットワーク機器設定
- Eメールによる通信
### 重要なポイント
- 非同期転送とは通信における一種のデータの転送方法のことです
- 同期転送は送信者と受信者の間で常にタイミングの同期を図り、送信者と受信者が同時にデータを送受信する
