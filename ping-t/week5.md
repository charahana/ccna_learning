# 間違えた問題まとめ
## 1. CSMA/CDの動作について正しい記述はどれか(2つ選択)
### 間違いポイント
アクセス制御方式を理解できなかった
### 正解
- ケーブルが使用されている間はデータを送信せずに待機する
- コリジョンを検出した場合はランダムな時間を待った後でデータを送信する
### 重要なポイント
CSMA/CDの仕組みは下記となる
- データを送信したいデバイスはケーブルが使用されていないかを確認する
- ケーブルが使用されていなければ、データの送信を開始する
- コリジョンが発生するとジャミング信号を送信し、各コンピュータにコリジョン発生を通知する
- ジャミング信号を受信するとランダムな時間を待機し、その後でデータを再送する

## 2. Windows PCでルーティングテーブルを表示するコマンドは次のうちどれか(2つ選択)
### 間違いポイント
Linuxコマンドと混同してしまった

### 重要なポイント

## 3. Cisco Merakiの特徴として正しい記述はどれか(3つ選択)
### 間違いポイント
クラウド管理の仕組みを理解できなかった
### 正解
- デバイスの一元管理を行う
- トラフィックの可視化によりネットワークの監視が容易
- デバイスの接続状況をリアルタイムに表示する
### 重要なポイント
- Cisco MerakiとはCiscoが提供するクラウドベースのネットワーク管理ソリューションのことです
- クラウド管理はルータやスイッチなどのネットワークデバイスをクラウドで管理する方法です
- クラウド管理と従来のネットワークを管理する内容は下記となる
| ユースケース | クラウド管理 | 従来の管理 |
| ------ | ------ | ------ |
| デバイス管理 | 全てのデバイスを一元管理 | サードパーティツールなどを使用して一元管理 |
| 展開 | ゼロタッチプロビジョニング(ZTP) | 手動またはスクリプトを使用したプロビジョニング |
| セキュリティポリシー | ダッシュボードから複数のデバイスに適用 | デバイスごとにポリシーを適用 |
| トラブルシューティング | ダッシュボードでネットワーク全体を把握 | デバイスごとにトラブルシューティング |
| 監視とレポート | ネットワーク全体を一元監視 | サードパーティツールでデータを関連付けて監視 |


## 4. オートネゴシエーション機能について正しい記述はどれか。
### 間違いポイント
オートネゴシエーションについて理解できなかった
### 正解
- 接続された両方のインターフェースで有効にすべきである
### 重要なポイント
- オートネゴシエーションとは対向のポートに応じて自身の通信速度や通信モードを自動で設定する機能のことです
- オートネゴシエーションの片方だけを有効にすると通信モードの不一致が発生する場合がある
