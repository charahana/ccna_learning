# 間違えた問題まとめ
## 1. ハイパーバイザーについて正しい記述はどれか。
### 間違いポイント
仮想化したサーバの構成のイメージを上手くいってなかった
### 正解
- 仮想マシンを作成するソフトウェアである
- 物理的な資源を仮想化する
### 重要なポイント
- 仮想マシンとはソフトウェアを使用して仮想的に作成したマシン(PCやサーバなど)です
- 仮想マシンを作成・管理するソフトウェアのことを「ハイパーバイザー」と呼ばれる
- CPUやメモリなどの物理リソースを仮想マシンへ割り当てる

## 2. マルチキャストについて正しい記述はどれか(3つ選択)
### 間違いポイント
ブロードキャストと同じ分類で理解してしまった
### 正解
- 複数の通信相手に同じパケットを届けるために使われる
- ビデオ会議などの動画のストリーミング配信に適している
- アドレスは「224.0.0.0～239.255.255.255」の中から使用する
### 重要なポイント
下記分類となる
| 伝送方式 | 説明 |
| ------ | ------ |
| ユニキャスト | 1対1の伝送方式 特定の相手に伝送する |
| マルチキャスト | 1対多の伝送方式 特定のグループ宛に伝送する |
| ブロードキャスト | 1対全の伝送方式 同一ネットワーク上の全てのデバイスに伝送する |

## 3. 仮想サーバから物理ネットワークに接続する順序で正しいものはどれか
### 間違いポイント
仮想化の意味を理解出来なかった
### 正解
- 仮想サーバ → vNIC → vSwitch → pNIC → 物理ネットワーク
### 重要なポイント
- 仮想サーバはvSwitchを経由して物理ネットワークに接続する
- vSwitchとはサーバ上のソフトウェアによって仮想的に作成するL2スイッチです
